# FortiGate Health Monitoring Dashboard

Grafana dashboard focused on operational health and network visibility for a Fortinet FortiGate appliance.

## Technical highlights

- Zabbix datasource integration.
- Device availability and overall health state.
- CPU and memory utilization.
- Temperature monitoring.
- Active sessions and session context.
- Interface state and traffic visibility.
- HA synchronization status handling.
- Custom HTML Graphics/CSS/JavaScript visualization and responsive KPI layout.
