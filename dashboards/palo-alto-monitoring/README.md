# Palo Alto Firewall Health Monitoring Dashboard

Grafana dashboard for Palo Alto Networks firewall health and interface visibility using Zabbix.

## Technical highlights

- Availability, CPU, memory and temperature KPIs.
- Management-plane/data-plane context where available.
- Interface status, input/output throughput and utilization.
- Traffic history visualization and sparklines.
- Interface table with automatic pagination.
- Custom device visualization built with HTML Graphics, CSS, SVG and JavaScript.

## Public-demo changes

Static device identifiers such as hostname, IP addresses, MAC address, serial number, interface aliases, provider names and data-center location were replaced with fictional values.
