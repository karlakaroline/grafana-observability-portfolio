# Importing the demo dashboards

1. Install the plugins required by the dashboard, such as the Zabbix datasource and HTML Graphics where applicable.
2. Create your own datasource(s) in Grafana.
3. Replace placeholder datasource UIDs in the JSON or remap them during import when your Grafana version supports it.
4. Update demo host, group, item and environment filters to match your own lab environment.
5. Validate queries in Query Inspector before adapting thresholds, mappings or status logic.
